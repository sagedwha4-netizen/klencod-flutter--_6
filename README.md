# ذكري | Dhikri
مشروع Flutter لمسبحة إلكترونية عربية، بتصميم زجاجي هادئ.

## الميزات
- يعمل دون حساب ودون إنترنت.
- يحفظ العد والإحصائيات على الجهاز عبر SharedPreferences.
- أذكار جاهزة مع أهداف مختلفة.
- اهتزاز اختياري.
- إنجازات مرئية ورسالة عند إكمال العدد.
- صفحات المسبحة والإنجازات والإحصائيات والإعدادات.

## المتطلبات
Flutter SDK حديث يدعم Dart 3.3 أو أحدث، وAndroid SDK.

## التشغيل
```bash
flutter pub get
flutter run
```

## بناء APK
للتجربة:
```bash
flutter build apk --debug
```
للإصدار:
```bash
flutter build apk --release
```
الملف الناتج:
`build/app/outputs/flutter-apk/app-release.apk`

## ملاحظات
- لا يستخدم Firebase أو تسجيل الدخول.
- لا توجد مزامنة بين الأجهزة؛ البيانات محفوظة محليًا.
- حذف التطبيق أو مسح بياناته قد يؤدي إلى فقدان الإحصائيات.
- يجب اختبار البناء على بيئة Flutter/Android SDK الفعلية قبل النشر.
